# Módulo 1 — Introducción

Corresponde al primer contenido básico del curso: introducción a la analítica de datos, conceptos clave de ciencia de datos, introducción a Orange Data Mining y repaso de manejo de datos en Python (ver [`PROGRAMA.md`](../PROGRAMA.md)).

## Materiales

- [`1.0_Motivacion.pdf`](1.0_Motivacion.pdf)
- [`1.1_Repaso_Python.ipynb`](1.1_Repaso_Python.ipynb) — Notebook de repaso de NumPy, Pandas y Matplotlib/Seaborn, en 3 niveles progresivos (básico, intermedio, un poco avanzado), cada uno con un ejercicio práctico al final **con verificación automática**: al guardar la respuesta en la variable indicada y ejecutar `verificar_ejercicio_N()`, el notebook dice si está bien o mal, sin mostrar la solución. Se sube **sin ejecutar** (sin salidas de celdas ni la solución del ejercicio), para que cada estudiante lo corra por su cuenta. Usa datos sintéticos generados en el propio notebook, así que no requiere descargar ningún archivo adicional; solo necesitas `pandas`, `numpy`, `matplotlib` y `seaborn` instalados.
- [`1.2_Orange_Data_Mining.md`](1.2_Orange_Data_Mining.md) — Qué es Orange Data Mining, sus ventajas frente a programar directamente en Python, y cómo descargarlo e instalarlo (instalador oficial, Anaconda o pip).
- [`1.3_Bases_de_datos_y_datasets.pdf`](1.3_Bases_de_datos_y_datasets.pdf) — Diapositivas: qué es un dataset, dónde encontrar datos (UCI, Kaggle, datos abiertos...), formatos de datos (CSV, Raw Text, hojas de cálculo, XML/JSON, SQL) y calidad de datos.
- [`1.4_Bases_de_Datos_y_Datasets_Ejemplos.ipynb`](1.4_Bases_de_Datos_y_Datasets_Ejemplos.ipynb) — Notebook de ejemplos para desarrollar en clase después de socializar las diapositivas anteriores: descarga un dataset del UCI Machine Learning Repository en formato **CSV** (*Wine Quality*) y otro en **Raw Text** (*Auto MPG*), explora cada uno con Pandas y lo visualiza con Matplotlib, y cierra con un ejemplo de carga y consulta de una **base de datos SQL** (SQLite) visualizada de la misma forma. Todo el código está comentado paso a paso. Se sube sin ejecutar; las secciones 1 y 2 requieren conexión a internet.
- [`1.5_Tipos_de_Variables.pdf`](1.5_Tipos_de_Variables.pdf) — Diapositivas: qué es una variable, clasificación general (cuantitativas/cualitativas, discretas/continuas, nominales/ordinales), una actividad de identificación, y cómo elegir entre gráfico de barras e histograma según el tipo de variable.
- [`1.6_Tipos_de_Variables_y_Visualizacion_Ejemplos.ipynb`](1.6_Tipos_de_Variables_y_Visualizacion_Ejemplos.ipynb) — Notebook de ejemplos para desarrollar en clase después de socializar las diapositivas anteriores: carga el *Spotify Tracks Dataset* de **Kaggle** (con `kagglehub`, incluye instrucciones para obtener la API key), clasifica sus columnas según el esquema de las diapositivas (incluyendo el caso "trampa" de columnas numéricas que en realidad son categóricas, como `key` o `mode`), y cierra con un gráfico de barras (variable cualitativa) y un histograma (variable cuantitativa continua). Todo el código está comentado paso a paso. Se sube sin ejecutar; requiere conexión a internet y una cuenta de Kaggle.

> Nota: el nombre "Bases de datos y datasets" ya se había usado para el material anterior (`1.3`/`1.4`); estas diapositivas tratan en realidad sobre **tipos de variables**, así que el material 1.5/1.6 se nombró en consecuencia.
