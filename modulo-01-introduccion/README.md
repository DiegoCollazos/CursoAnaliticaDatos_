# Módulo 1 — Introducción

Corresponde al primer contenido básico del curso: introducción a la analítica de datos, conceptos clave de ciencia de datos, introducción a Orange Data Mining y repaso de manejo de datos en Python (ver [`PROGRAMA.md`](../PROGRAMA.md)).

## Materiales

- [`1.0_Motivacion.pdf`](1.0_Motivacion.pdf)
- [`1.1_Repaso_Python.ipynb`](1.1_Repaso_Python.ipynb) — Notebook de repaso de NumPy, Pandas y Matplotlib/Seaborn, en 3 niveles progresivos (básico, intermedio, un poco avanzado), cada uno con un ejercicio práctico al final. Usa datos sintéticos generados en el propio notebook, así que no requiere descargar ningún archivo adicional; solo necesitas `pandas`, `numpy`, `matplotlib` y `seaborn` instalados.
