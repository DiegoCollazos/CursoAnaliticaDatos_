# Introducción a Orange Data Mining

## ¿Qué es Orange Data Mining?

**Orange** es un software de código abierto para minería de datos, aprendizaje automático (machine learning) y visualización interactiva. Está desarrollado por el laboratorio de bioinformática de la Universidad de Ljubljana (Eslovenia) y construido en Python.

Su característica principal es la **programación visual**: en lugar de escribir código, se arman flujos de análisis (workflows) arrastrando y conectando **widgets** —pequeños bloques que cargan datos, los transforman, entrenan modelos o los visualizan— en un lienzo (canvas). Cada widget recibe datos de los widgets anteriores y pasa su resultado a los siguientes, como un diagrama de flujo ejecutable.

En este curso usaremos Orange para explorar de forma rápida e intuitiva los mismos conceptos que trabajamos en Python (preprocesamiento, visualización, clustering, clasificación, regresión), antes o en paralelo a implementarlos con código.

## Ventajas de Orange Data Mining

- **No requiere programar**: ideal para prototipar un análisis completo y entender su flujo de principio a fin sin escribir una sola línea de código.
- **Programación visual**: el workflow *es* la documentación del análisis — se explica y se lee como un diagrama.
- **Interactividad**: los gráficos son interactivos y están conectados entre sí (seleccionar puntos en un gráfico resalta esos mismos datos en los demás widgets).
- **Gratuito y de código abierto**, con una comunidad activa y documentación amplia.
- **Multiplataforma**: funciona igual en Windows, macOS y Linux.
- **Extensible mediante complementos (add-ons)**: minería de texto, análisis de imágenes, bioinformática, datos geoespaciales, entre otros.
- **Compatible con Python**: por debajo usa NumPy, SciPy y scikit-learn, y trae un widget de *Python Script* para combinar lo visual con código cuando se necesite algo más avanzado.
- **Curva de aprendizaje baja**: es una excelente puerta de entrada a conceptos de analítica de datos y ML para quienes recién empiezan.

## Requisitos del sistema

- Windows 10/11, macOS 10.14 o superior, o una distribución de Linux reciente.
- Aproximadamente 2 GB de espacio libre en disco.
- Conexión a internet solo para la descarga e instalación de complementos.

## Cómo descargar e instalar Orange

### Opción 1 — Instalador oficial (recomendada)

Es la forma más simple: el instalador ya incluye Python y todas las dependencias necesarias, sin configuración adicional.

1. Ir al sitio oficial de descargas: **https://orangedatamining.com/download/**
2. Elegir el instalador correspondiente a tu sistema operativo (Windows, macOS o Linux).
3. Ejecutar el instalador descargado y seguir el asistente (siguiente → siguiente → instalar).
4. Al finalizar, abrir **Orange** desde el menú de aplicaciones de tu sistema.

### Opción 2 — Con Anaconda / conda

Si ya usas Anaconda o Miniconda (por ejemplo, porque también trabajas con Python para este curso), puedes instalar Orange en un entorno:

```bash
conda create -n orange3 python=3.11
conda activate orange3
conda install -c conda-forge orange3
```

Para abrir la aplicación:

```bash
orange-canvas
```

### Opción 3 — Con pip

```bash
pip install orange3
orange-canvas
```

> 💡 Si tu equipo ya tiene una instalación de Python para otras cosas, se recomienda usar un entorno virtual (conda o `venv`) para instalar Orange, en vez de instalarlo en el Python del sistema.

### Verificar que quedó instalado correctamente

Al abrir Orange debería aparecer la **pantalla de bienvenida**, con la opción **"New"** para crear un workflow nuevo y una lista de ejemplos recientes. Si ves esa pantalla, la instalación fue exitosa.

## Primeros pasos

1. Crea un workflow nuevo (**New**).
2. En el panel izquierdo busca el widget **File** y arrástralo al lienzo — permite cargar un archivo de datos (CSV, Excel, o los datasets de ejemplo incluidos, como *iris*).
3. Arrastra el widget **Data Table** y conéctalo al widget **File** (arrastra desde el borde derecho de *File* hasta *Data Table*) para ver los datos cargados en forma de tabla.
4. Prueba agregar un widget **Scatter Plot** conectado a **File** para visualizar dos variables — notarás que es completamente interactivo.

Con esos cuatro pasos ya tienes tu primer flujo de análisis funcionando en Orange.
