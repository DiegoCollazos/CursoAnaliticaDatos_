Se guarda solo en este navegador (localStorage) y se usa únicamente para hablar con la API de GitHub, nunca se comparte con nadie más. Crea el tuyo en GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) y marca el permiso repo. Importante: usa un token clásico ("classic"), no un "fine-grained token" — los fine-grained solo dejan elegir como "Resource owner" tu propia cuenta o una organización a la que pertenezcas, así que nunca van a funcionar como colaborador de un repositorio de otra persona. Trátalo como una contraseña: no lo compartas ni lo uses en computadores públicos.

Datos de la entrega

Si el trabajo es en pareja, separa los dos apellidos con un guion bajo, ej. Perez_Gomez.
Puedes seleccionar varios archivos a la vez (por ejemplo, el .ows y el .pdf de evidencias). Tamaño recomendado: menor a 20 MB por archivo.

¿Cómo funciona?

Tu entrega no se sube directamente a la rama principal del curso. Esta página crea una rama nueva solo para tu entrega, sube ahí tus archivos, y abre un Pull Request para que el docente lo revise y lo fusione. Si vuelves a subir archivos con la misma categoría y los mismos apellidos (por ejemplo, para corregir algo antes de la fecha límite), se agregan al mismo Pull Request en vez de crear uno nuevo.
