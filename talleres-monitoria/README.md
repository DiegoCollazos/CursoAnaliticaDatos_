# Talleres de monitoría

Talleres prácticos complementarios orientados por el monitor del curso, pensados para reforzar con ejercicio autónomo los temas vistos en los módulos del curso.

## Materiales

- [`Taller_Practico_PowerBI.pdf`](Taller_Practico_PowerBI.pdf) — **Taller práctico: Power BI & Data Analytics Integration.** Integración híbrida de datos y visualización avanzada combinando Power BI con Python. Cada estudiante elige una temática libre (ventas, salud, clima, deportes, etc.) y construye un tablero de control a partir de datos propios, siguiendo cuatro fases:
  1. **Adquisición de datos**: cargar al menos 1.000 registros provenientes de 3 fuentes distintas, una de ellas necesariamente generada o cargada mediante un script de Python.
  2. **Transformación con Python en Power Query**: crear una columna calculada ejecutando un script de Python dentro del Editor de Power Query (se incluye un ejemplo base con `pandas`).
  3. **Visualización**: combinar al menos 2 gráficos nativos de Power BI con al menos 2 gráficos construidos con el objeto visual de Python.
  4. **Entregable**: un archivo `.pbix` con las 3 tablas de datos, la columna calculada con Python visible, un dashboard de una sola página con los 4 gráficos mínimos, y un cuadro de texto con la interpretación de lo descubierto al comparar las 3 fuentes.

  Requiere Power BI Desktop y Python instalados, con las librerías `pandas`, `numpy`, `matplotlib` y `seaborn`, y la ruta de Python configurada en Power BI (*Archivo > Opciones y configuración > Opciones > Creación de scripts de Python*).
